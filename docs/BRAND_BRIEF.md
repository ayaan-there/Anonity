# Anonity Brand Brief

## Tagline

Prove the bug. Keep the identity.

## Three key messages

1. Researchers can submit useful vulnerability reports without creating a hunter account or publishing a wallet identity.
2. Midnight verifies authority and payout rights with proofs instead of requiring a public identity trail.
3. Report content is encrypted in the browser for the correct organization and hunter; the database stores ciphertext.

## Color palette

- Primary: Midnight black `#0b0d10`
- Surface: Graphite `#151922`
- Accent: Electric cyan `#20e0c0`
- Warning: Demo yellow `#f5c542`
- Text: Soft white `#f1f4f6`

## X bio

Anonymous bug bounties on Midnight. Prove the report, keep the identity. Preprod testing now open.

## X banner concept

A near-black technical grid with a single cyan proof path passing through redacted identity blocks. Use the yellow only for the explicit unshielded-mode confirmation action.
